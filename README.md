Garmin FIT to Excel
Python script that automatically processes Garmin FIT files and imports the activity data into an Excel spreadsheet.
The script searches for Garmin ZIP exports in the Windows Downloads folder, extracts the FIT files, reads the activity information and adds the data to an Excel workbook.

Features
•	Automatically finds Garmin ZIP files in the Downloads folder
•	Extracts .FIT activity files from the ZIP files
•	Reads activity data using fitdecode
•	Creates or updates an Excel workbook
•	Automatically detects duplicate activities
•	Creates a backup of the original FIT files
•	Converts Garmin activity data into readable values
•	Calculates running pace, cycling speed and swimming pace
•	Imports heart-rate data
•	Imports aerobic and anaerobic training effect
•	Imports RPE and workout feeling
•	Calculates the ISO week number
•	Calculates training load
•	Formats the Excel data automatically
•	Deletes successfully processed ZIP files from the Downloads folder

Excel data
The generated Excel file contains the following columns:
Column	Description
Datum	Date of the activity
Sport	Type of activity
Duur/tijd	Activity duration
Afstand (km)	Distance in kilometres
Tempo / snelheid	Running pace, cycling speed or swimming pace
Gem. hartslag	Average heart rate
Max hartslag	Maximum heart rate
Aeroob effect	Garmin aerobic training effect
Anaeroob effect	Garmin anaerobic training effect
RPE	Rate of perceived exertion
Gevoel	Garmin workout feeling
Activiteit ID	Unique FIT file/activity identifier
Weeknummer	ISO week number
Load	Calculated training load

Supported activities
The script currently recognizes:
•	Running → Hardlopen
•	Cycling → Fietsen
•	Swimming → Zwemmen
•	Walking → Wandelen
•	Hiking → Wandelen
•	Training → Fitness
•	Fitness → Fitness
•	Other activities → Overig

How it works
1.	Export Garmin activities as a ZIP file.
2.	Place the ZIP file in the Windows Downloads folder.
3.	Run the Python script.
4.	The script finds all ZIP files in Downloads.
5.	FIT files are extracted and processed.
6.	Activity data is added to garmin_activiteiten.xlsx.
7.	FIT files are saved in the FIT_backup folder.
8.	Successfully processed ZIP files are removed from Downloads.
Existing activities are identified using their activity ID, preventing the same activity from being imported twice.

Installation
Install Python and then install the required packages:
pip install -r requirements.txt

Running the script
Run the Python file from the project folder:
python main.py
Replace main.py with the actual filename of the Python script if it has a different name.

Notes
The script currently expects Garmin ZIP exports to be located in the user's Windows Downloads folder.
The generated Excel workbook is stored in the same folder as the Python script.
